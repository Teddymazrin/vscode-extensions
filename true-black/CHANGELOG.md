# Changelog

All notable changes to the True Black VSCode extension are documented here.

## [0.5.1] — 2026-10-27

### Changed
- Source moved to the [vscode-extensions](https://github.com/Teddymazrin/vscode-extensions/tree/main/true-black) repo; repository, homepage and issue links updated
- Fixed the README screenshot link

## [0.2.0] — 2026-04-18

### Added
- Initial release of True Black as a lightweight Dark+ wrapper
- Pure `#000000` backgrounds across editor, sidebar, activity bar, title bar, terminal, panels, tabs, and status bar
- Dark+'s syntax highlighting inherited automatically — no custom token colors
